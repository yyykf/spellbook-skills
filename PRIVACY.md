# Privacy Policy

Spellbook Skills is a local plugin bundle. The skills, hooks, and installer scripts in this repository do not include telemetry, analytics, or hosted tracking.

## Data Handling

The plugin may read local repository files when an agent follows a skill or when the optional Project Context Hook injects project-memory guidance. That data stays in the user's local agent session and is not sent to a Spellbook Skills service.

Some skills help users call external tools or services, such as Git hosting, GitLab, GitHub, or YApi. In those cases, data handling is controlled by the command the user chooses to run and by that external service's own policy.

## Network Access

The plugin itself does not contact a Spellbook Skills backend. Installer examples may download scripts from this public GitHub repository when the user chooses a remote install path.
